# brainmelt
A Brainfuck compiler written in Rust.

## Install
1. Run Terminal
2. Run `git clone https://github.com/tarutarudev/brainmelt.git && cd brainmelt && rm -rf .git && RUSTFLAGS="-C target-cpu=native" cargo build --release`

## Usage
`./brainmelt <FILE>`

Example: 
`./brainmelt snakegame.bf`
